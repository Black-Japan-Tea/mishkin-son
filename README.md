# mishkin-son

Суточный трекер сна и кормлений младенца. Мобильное PWA: офлайн-first (IndexedDB),
облако и синк — Supabase. Полный план продукта — [PLAN.md](PLAN.md).

## Быстрый старт

```bash
npm install
npm run dev
```

## Настройка Supabase (нужна перед первым входом)

1. Создай проект на [supabase.com](https://supabase.com).
2. SQL Editor → выполни по очереди:
   - `supabase/migrations/0001_tables.sql`
   - `supabase/migrations/0002_rls.sql`
   - `supabase/migrations/0003_functions.sql`
3. Project Settings → API → скопируй **URL** и **anon public key**.
4. Скопируй `.env.example` в `.env`, вставь значения:
   ```
   VITE_SUPABASE_URL=https://xxx.supabase.co
   VITE_SUPABASE_ANON_KEY=eyJ...
   ```
5. Перезапусти `npm run dev` — экран настройки сменится входом.

Приложение до настройки облака работает как «витрина конфигурации»: данные не теряются,
но вход недоступен (по решению опроса гостевого режима нет).

## Семья и приглашения

Первый пользователь создаёт семью (экран после входа) и генерирует код приглашения
в **Настройках → Семья**. Второй родитель/бабушка регистрируются и вступают по коду.

| Команда | Что делает |

| `npm run dev` | Дев-сервер Vite |

## Архитектура (кратко)

- **Данные:** единственный источник правды на устройстве — IndexedDB (`idb`); каждое событие
  рождается с клиентским uuid и попадает в очередь `outbox`.
- **Синк:** push outbox → RPC `push_*` с защитой last-write-wins по `updated_at`;
  pull событий по курсору `updated_at`. Триггеры: появление сети, возврат в приложение,
  кнопка в настройках.
- **Советы:** детерминированный офлайн-движок (нормы возраста + личные паттерны), без ML.
- **Темы:** светлая (крем/персик/шалфей) и тёмная (cursor-стиль: зелёный/оранжевый/фиолетовый),
  4 режима включая расписание; амбиентная подсветка карточки сна и кнопок (рецепт z.ai).

## Известные границы v1

- Без пушей/напоминаний, без здоровья/лекарств, без ролей в семье, без CSV — см. PLAN.md §16–18.
- Экспорт — JSON; удаление аккаунта — v2.
- Кривые ВОЗ — упрощённые (медиана ±2SD), не медицинская оценка.
