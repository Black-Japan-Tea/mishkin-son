## 2. P0 — блокер прода (сделать до косметики) — ✅ волна 1 (агент A, 2026-11-06)

**Симптом** (воспроизведён на проде 2026-11-05): при устаревшем кэше PWA открытие «Статистики» — **белый экран**, весь DOM пуст. Консоль: 404 на `assets/SleepBars-*.js` и соседние чанки + «Failed to fetch dynamically imported module» (скриншот `.playwright-mcp/t8_stats_320_broken.png`). После ручной перезагрузки приложение самолечится (SW обновляется, тайтл меняется «Мишкин сын» → «Мишкин сон»).

**Причина**: сервис-воркер отдаёт старый закэшированный `index.html`; тот ссылается на хэши чанков, удалённые с сервера новым деплоем → 404; `React.lazy` без error boundary роняет всё дерево.

**Работы**:
1. Error boundary вокруг маршрутов: при ошибке загрузки чанка — один автоматический reload (с защитой от цикла, например флаг в `sessionStorage`) и понятное сообщение, иначе — кнопка «Перезагрузить».
2. Стратегия SW для навигаций: не отдавать устаревший HTML, когда ассеты сменились (network-first для навигаций с fallback на кэш, или пересмотр `navigateFallback` в `vite.config.ts`).
3. Деплой-смоук после каждого релиза (скрипт/чек): `curl` главной (тайтл «Мишкин сон», 200), открыть `/stats` и `/tips` свежим браузером без кэша — чанки не 404.
4. Мелочь из консоли: заменить deprecated `apple-mobile-web-app-capable` на `mobile-web-app-capable` (`index.html`).

**Приёмка**: смоделированный «старый кэш» → «Статистика» открывается или восстанавливается сама ≤ 1 reload; деплой-смоук зелёный.
